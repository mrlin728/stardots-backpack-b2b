# Carry what comes next — local creative direction

A travel-object editorial: bags as companions for the next journey. A burgundy opening, parchment catalog pages and an acid-yellow final invitation form distinct chapters. DM Sans provides a large, close-set grotesk hierarchy; hairline rules and model codes provide rhythm. Existing illustrative brand collection image is the hero focal asset, explicitly captioned as illustrative; all catalog photography comes from the existing Stardots archive and is downloaded locally with source mapping in local-media-provenance.json. No new product, customer or certification claims.

Sequence: strong opening / curated reference objects / product-family index / development notebook / buyer reading / invitation. Interior pages retain their full bilingual information architecture and inquiry context. One GSAP choreography system and one Lenis scroll engine, bypassed for reduced motion, with clean route teardown. No Three.js: catalog photographs and typography are the meaningful material; a canvas would add weight without information.

Dependency review, 2026-10-07: gsap 3.15.0 from official npm metadata, GSAP Standard no-charge license (https://gsap.com/standard-license/), unpacked 6,258,071 bytes; lenis 1.3.26, MIT, unpacked 457,528 bytes. No install lifecycle scripts in either; installation ignores scripts. DM Sans is Google Fonts OFL-1.1, bundled with its license. No external font loading.

Local preview only. All inquiry submissions prepare an email draft; the buyer sends manually in their email client. Production API deployment is disabled in this copy. No deployment command or production integration is executed.
